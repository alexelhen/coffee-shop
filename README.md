# Зерно

Учебный проект, интернет-магазин кофе. Без фреймворков, только HTML, SCSS и обычный JavaScript.

## Запуск

Каталог подтягивается из products.json, поэтому просто открыть index.html двойным кликом мало, браузер заблокирует запрос. Нужен любой локальный сервер:

    python -m http.server 8000

Дальше заходим на http://localhost:8000

## Стили

Исходники в папке scss, собранный файл в css/style.css. Пересобрать:

    sass scss/main.scss css/style.css
